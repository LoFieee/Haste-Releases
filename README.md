# Haste Releases

Official public releases for **Haste**.

This repository is used only to distribute compiled versions of Haste.  
The application source code is maintained separately and is not published here.

## Download

Go to the **Releases** section of this repository and download the latest:

```text
Haste-Setup.exe
```

For most users, this is the recommended way to install or update Haste.

## Updates

Haste can check this repository automatically for new versions.

When a newer release is available, the application can download the latest installer directly from the GitHub Release assets.

Release tags follow this format:

```text
v1.1.1
v1.2.0
v2.0.0
```

## Installation

1. Download `Haste-Setup.exe` from the latest release.
2. Run the installer.
3. Follow the installation steps.
4. Launch Haste.

When updating an existing installation, simply run the newer installer over the current version.

## Release assets

Each release should normally include:

```text
Haste-Setup.exe
```

Additional files may be provided when needed.
